
# 📊 Crypto Market Live Data Tracker  

This project fetches real-time cryptocurrency market data using the **CoinGecko API**, processes the data, and saves it into an Excel file with live updates every 5 minutes. Additionally, an analysis report summarizes key insights from the fetched data.

## 🚀 Features  
- **Fetches real-time cryptocurrency data** (name, symbol, price, market cap, volume, etc.)  
- **Saves data to an Excel file** and updates it automatically  
- **Generates a report** with key insights from the dataset  
- **Google Drive link** to view the live-updated Excel sheet  

## **Dependies**
pip install pandas openpyxl requests schedule  

##**Insights from Data**
The top cryptocurrencies by market cap
Price fluctuations in the last 24 hours
Trading volume trends
**🛠 Technologies Used**
Python (Requests, Pandas, OpenPyxl, Schedule)
CoinGecko API (Real-time Crypto Data)
